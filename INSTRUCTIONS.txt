SYSTEM: macOS Tahoe 26.5 | Apple M4 Pro | Python 3.13.5 | VS Code 1.119.0

================================================================================
PART 1: SYSTEM PREPARATION
================================================================================

1. Install Homebrew (if not installed):
   ----------------------------------------
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

2. Install ffmpeg:
   ----------------
   brew install ffmpeg

3. Verify ffmpeg:
   ---------------
   ffmpeg -version

4. Verify Python 3.13.5:
   ----------------------
   python3 --version

================================================================================
PART 2: PROJECT SETUP
================================================================================

5. Create project directory:
   -------------------------
   mkdir -p ~/WebApps/mp3-converter
   cd ~/WebApps/mp3-converter

6. Create virtual environment:
   ---------------------------
   python3 -m venv .venv

7. Activate virtual environment:
   -----------------------------
   source .venv/bin/activate

   (Your prompt should now show: (.venv) at the beginning)

8. Upgrade pip:
   -------------
   pip install --upgrade pip

9. Install Python dependencies:
   ----------------------------
   pip install tqdm

10. Verify tqdm installation:
    --------------------------
    pip list | grep tqdm

================================================================================
PART 5: USAGE
================================================================================

18. Single file conversion:
    ------------------------
    python mp4_to_mp3.py song.mp4

19. Custom output location:
    ------------------------
    python mp4_to_mp3.py concert.mp4 ~/Music/

20. Batch conversion (all MP4s in folder):
    -----------------------------------------
    python mp4_to_mp3.py --batch ~/Downloads/rips/

21. Recursive batch conversion:
    ----------------------------
    python mp4_to_mp3.py --batch ~/Downloads/rips/ --recursive

22. Quality presets:
    -----------------
    python mp4_to_mp3.py --preset archive symphony.mp4    # 320kbps
    python mp4_to_mp3.py --preset voice podcast.mp4         # 128kbps
    python mp4_to_mp3.py --preset music track.mp4           # 256kbps (default)

23. View help:
    -----------
    python mp4_to_mp3.py --help
